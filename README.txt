Little Joys v0.3 — smiley logo + photo moments + optional microphone experiment

NO CODING NEEDED: Update your SAME Netlify site. In Netlify: open the existing site, go to Deploys, then drop the EXTRACTED little-joys-v03 folder into the upload/deploy zone. Do not create a new site. The extracted folder contains index.html at its root.

New features included:
- Smiley icon on website and on mobile home screen.
- Capture a happy moment with a photo from camera or gallery and a short note.
- Optional microphone demo: tap Start listening and allow microphone access in the browser; a volume/rhythm heuristic looks for laughter-like bursts in real time. If it hears a possible laugh, YOU confirm or dismiss it. No laugh is saved automatically.
- It works only while the app is open on the Today screen. Stops on background, screen lock, leaving Today, or pressing Stop listening.
- Raw audio is never recorded, uploaded, saved, or transcribed. Audio processing is local on device.

IMPORTANT: This microphone version is an experimental prototype, NOT a validated laughter classifier. Speech, music, coughing, and other noises can cause false alerts; quiet laughter can be missed. Browser and device permission or foreground restrictions apply. Requires HTTPS and user permission. iOS Home Screen apps may ask for permission on each launch.

Your existing journal should remain saved in the SAME browser on the SAME Netlify address; please export a backup from You before updating. Photos are saved only in that browser's IndexedDB; backup includes photos.
